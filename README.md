# 太阳系 · 宇宙尺度之旅

一个可交互的太阳系动画。从地球出发，按对数缩放一路拉远到银河系，用真实的距离比例和光行时间展示宇宙有多广阔。

**在线体验：<https://lqiaoqing.github.io/solar-system/>**

手机和微信里可以直接打开，竖屏、横屏都能用。整个页面是一个独立文件，不加载任何外部资源。

## 内容

打开后会自动漫游，共 11 个层级：

地球 → 地月系统 → 内太阳系 → 小行星带与木星 → 八大行星 → 柯伊伯带与冥王星 → 日球层与旅行者号 → 奥尔特云 → 比邻星 → 太阳邻域 → 银河系

每一层都有比例尺、测距线和光行时间，例如：

| 距离 | 光要走多久 |
| --- | --- |
| 地球到月球（38.44 万千米） | 1.28 秒 |
| 太阳到地球（1 天文单位） | 8 分 19 秒 |
| 太阳到海王星（约 30 天文单位） | 约 4 小时 10 分 |
| 太阳到旅行者 1 号（约 172 天文单位） | 约 24 小时 |
| 太阳到比邻星 | 4.24 年 |
| 太阳到银河系中心 | 约 2.6 万年 |

画面细节：

- 行星位置按 JPL 轨道根数实时计算，模拟日期从打开页面的当天开始，月相与真实日期对应
- 太阳有日冕、临边昏暗和随自转移动的黑子；行星的昼夜分界线始终背向太阳
- 会转的地球大陆，木星条带与大红斑，带卡西尼缝的土星环（倾角 26.7°），躺着自转的天王星（约 98°）
- 伽利略四卫星、土卫六、海卫一、卡戎
- 按开普勒定律内快外慢转动的小行星带（可见柯克伍德空隙），木星前后 60° 的特洛伊小行星
- 柯伊伯带、奥尔特云，彗尾始终背向太阳的恩克彗星，哈雷彗星轨道
- 旅行者 1、2 号，27 颗邻近恒星与深空天体，带旋臂的银河系

## 操作

| 操作 | 方法 |
| --- | --- |
| 自动漫游 | 打开即开始；任何操作都会接管，点「漫游」继续 |
| 缩放 | 鼠标滚轮、手机双指、「＋/－」按钮，或拖动右侧刻度尺 |
| 平移 / 复位 | 拖动画面；双击空白处或点「⊙ 回中」 |
| 切换层级 | 「‹ ›」按钮 |
| 时间 | 暂停、倒流、调速（实时到每秒 10 年），「今天」回到当前日期 |
| 显示 | 「标签」「轨道」开关 |
| 真实大小 | 天体按真实比例显示，行星会小到几乎看不见 |
| 大小对比 | 太阳和各行星用同一比例尺并排显示 |
| 天体资料 | 点击天体弹出资料卡；「飞往并跟随」让镜头一直跟着它 |
| 键盘 | `+` `-` 缩放，空格暂停，`←` `→` 切换层级，`J` `L` `O` `C` `Esc` |

## 哪些是真实比例

**完全真实：**

- 所有轨道的大小比例、偏心率、近日点方向和公转周期。比如海王星 30.07 天文单位与地球 1 天文单位的比例是准确的。
- 各层级的距离和光行时间。
- 在「地球」和「地月系统」两层，天体大小也是真实的。

**经过放大：**

- 其他层级的天体图标被放大了，否则根本看不见。放大倍数实时显示在左下角，例如在「八大行星」层，地球约放大 8,700 倍。
- 行星之间的大小差距被压缩了（显示半径约等于真实半径的 0.55 次方），木星显示为地球的约 3.8 倍，实际是 11 倍，但大小顺序不变。
- 想看准确的大小关系，请用「大小对比」，太阳是地球的 109 倍。

## 已知局限

- 视角是从黄道面正上方俯视，冥王星（17°）、哈雷彗星等倾斜轨道被投影到平面上。
- 行星图标采用侧面画法，条纹水平、土星环按经典角度绘制，并非真实的俯视外观。
- 银河系旋臂、日球层形状、奥尔特云边界是示意；小行星带、柯伊伯带、奥尔特云中的点按统计分布生成，不对应真实个体。
- 月球位置为简化算法，误差约 1°；其他卫星的距离和周期是真实的，初始位置为随意设定。
- 轨道根数在 1800 到 2050 年最准，时间走到 1800 年之前或 2300 年之后会自动暂停。
